全局业务设置
这里维护所有公众号和查询 Web 共用的全局业务配置。账号级回复内容和密钥仍在公众号配置页维护。
这里的排行榜规则是共享榜单配置。公众号查询和客户 Web 查询命中后，会写进同一份排行榜，并按订单号全局去重。
规则命中逻辑：查单后若商家名包含关键词，且接单时间命中默认时间段或某日覆盖时间段，则自动进入同一份排行榜。排行榜地址留空时会自动使用短链公开域名；短链域名未配置或仍是 localhost 时使用服务器访问地址。删除后会从当前列表隐藏，历史数据不会删除，可显示已删除规则后恢复。
建议一个品牌一条规则；同一规则下可填多个关键词。
