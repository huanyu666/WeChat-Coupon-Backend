# 订单查询使用说明

这份说明是给用户看的，按步骤操作即可。

## 功能说明

发送指定关键词后，可以查询美团订单的下单时间/接单时间信息。

常见触发词：

- `订单查询`
- `查询订单`
- `查订单`
- `美团接单时间`

实际以公众号当前设置为准，如果管理员改过触发词，请按公众号提示使用。

## 使用前准备

使用订单查询前，你可能会遇到下面两种情况：

1. 需要先输入激活码
2. 免激活码，直接发链接即可

如果系统提示你输入激活码，就先按提示输入激活码。

## 完整使用流程

### 第一步：发送触发词

先给公众号发送：

```text
订单查询
```

或者：

```text
查询订单
```

### 第二步：按提示完成认证

如果系统提示：

```text
请输入激活码
```

那就直接发送你的激活码。

如果系统没有要求激活码，而是直接提示你发送美团链接，那就直接进入下一步。

### 第三步：发送美团链接

登录美团后，复制系统要求的那个美团链接，直接发给公众号。

如果你不会获取链接：

- 按公众号里的教程操作
- 有些号会提供“接单时间”教程按钮或图片

### 第四步：如果系统提示“选择上次帐号 / 使用新帐号”

如果你最近查过订单，系统可能会提示你二选一：

1. `使用上次记录帐号`
2. `使用新帐号`

说明：

- `使用上次记录帐号`：直接用你上一次查订单保存的美团帐号继续查
- `使用新帐号`：重新发送新的美团链接

如果你当前查的还是同一个美团帐号，直接点 `使用上次记录帐号` 会更方便。

如果你换了美团帐号，就选 `使用新帐号`。

### 第五步：等待查询结果

系统收到有效链接后，会自动开始查询。

查询完成后会返回订单相关结果。

如果当前请求较多，可能会稍微等待一下，这属于正常情况。

## 查询失败时怎么办

### 1. 提示激活码格式不正确

说明你发送的内容不像激活码。

处理方法：

- 重新发送正确的激活码
- 不要多带空格、中文符号或其他文字

### 2. 提示激活码验证失败

可能原因：

- 激活码无效
- 激活码已过期
- 激活码已被用完

处理方法：

- 重新获取新的激活码
- 再重新发送

### 3. 提示无法从链接中提取有效信息

说明你发送的链接不对，或者链接不完整。

处理方法：

- 重新登录美团
- 重新复制完整链接
- 按教程重新发送

### 4. 提示网络繁忙 / 网络超时 / 服务繁忙

这类情况通常是临时请求异常。

处理方法：

- 可以直接发送 `重试`
- 或者重新发送一次美团链接

### 5. 提示重试参数已失效

说明上一次的查询上下文已经过期。

处理方法：

- 重新发送触发词
- 再重新发送美团链接

## 可以使用的常见指令

在查询流程中，常见可用指令有：

- `取消`
- `退出`
- `返回`
- `重试`

说明：

- `取消 / 退出 / 返回`：结束当前查询流程
- `重试`：对上一次失败的查询再次发起请求

## 推荐操作顺序

给用户的最简单说法就是：

1. 发送 `订单查询`
2. 如果提示激活码，就先发激活码
3. 再发美团链接
4. 如果提示选帐号，就按需要选择
5. 等待结果
6. 如果失败，就发 `重试` 或重新发链接

## 常见问答

### 问：每次都要输入激活码吗？

不一定。

有些公众号配置的是：

- 需要激活码
- 有效期内只要验证过一次，后面可继续使用
- 或者直接免激活码

具体以当前公众号实际提示为准。

### 问：为什么会提示“使用上次记录帐号”？

因为系统记录了你最近查询过的美团帐号信息，方便你下次直接复用，不用每次重新复制链接。

### 问：查不到结果怎么办？

先按下面顺序排查：

1. 链接是不是最新复制的
2. 美团登录是否过期
3. 激活码是否有效
4. 直接发送 `重试`
5. 不行就重新走一遍流程

## 一句话版教程

```text
发送“订单查询” -> 按提示发激活码（如果需要） -> 再发美团链接 -> 等待结果
```
