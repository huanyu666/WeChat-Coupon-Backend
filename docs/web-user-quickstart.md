# Web 端快速上手

访问地址：

- `https://98vx.cn/web/login`

## 1. 注册 / 登录

第一次使用先注册账号。

注册成功后：

- 如果系统已开启自动审核，可以直接登录
- 如果系统未开启自动审核，需要等管理员通过后再登录

登录成功后会进入：

- `https://98vx.cn/web/query`

---

## 2. 添加 Token

进入查询页后，先点击：

- `添加Token`

需要填写：

1. 备注
2. 美团链接

系统会自动从美团链接里提取：

1. `UserID`
2. `Token`

添加完成后，建议点一次：

- `刷新所有状态`

确认 Token 显示为 `在线`。

> 插图建议 2：
> 添加 Token 弹窗截图

---

## 3. 查询订单

在 `查询任务` 区域：

1. 先选择 Token
2. 点击 `一键查询`

也可以手动输入订单 ID，再点击：

- `查询手动输入的订单`

> 插图建议 3：
> 查询任务区域截图

---

## 4. 查询津贴

在 `津贴查询` 区域：

1. 先选择 `大额津贴` 或 `小额津贴（免单）`
2. 系统会自动读取当前 Token 的历史地址
3. 选择地址
4. 点击 `创建津贴任务`

查询完成后可以看到：

1. 津贴摘要
2. 商家列表
3. 领券按钮
4. 打开美团 App 按钮

## 5. 常见问题

### Token 不在线

说明登录态可能失效了，重新获取新的美团链接，再重新添加 Token。

### 津贴查不到

可以尝试：

1. 切换地址
2. 切换大额 / 小额
3. 刷新 Token 状态后重试

### 提示请先选择地址

先点 `刷新地址`，重新选择一个地址后再查。

---

## 6. 最简步骤

```text
注册/登录 -> 添加Token -> 选择Token -> 查订单或查津贴
```
