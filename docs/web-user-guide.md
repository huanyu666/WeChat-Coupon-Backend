# Web 端使用说明

适用地址：`https://98vx.cn/web/login`

这份说明面向普通用户，按顺序操作即可。

---

## 1. 功能简介

Web 端目前主要提供两类能力：

1. 订单查询
2. 津贴查询

其中津贴查询又分为：

1. 大额津贴
2. 小额津贴（免单）

使用前需要先注册账号、登录账号，并添加自己的美团 Token。

---

## 2. 注册账号

打开登录页：

- `https://98vx.cn/web/login`

在页面顶部切换到 `注册`。

需要填写：

1. 用户名
2. 密码
3. 确认密码
4. 验证码

填写完成后，点击 `注册账号`。

### 注册成功后会出现两种情况

情况 1：系统已开启自动审核  
页面会提示：

```text
注册成功，账号已通过，现在可以直接登录
```

情况 2：系统未开启自动审核  
页面会提示：

```text
注册成功，请等待管理员审核
```

如果提示等待审核，请稍后再登录。

## 3. 登录账号

注册成功后，切换回 `登录` 标签。

填写：

1. 用户名
2. 密码
3. 验证码

点击 `登录系统`。

登录成功后会进入查询页面：

- `https://98vx.cn/web/query`

> 登录页截图，标出验证码位置和“登录系统”按钮。

## 4. 首次使用前：添加 Token

进入查询页后，先找到 `Token管理` 区域。

点击：

- `添加Token`

系统会弹出窗口，需要填写：

1. 备注（自己给这个账号起的名字）
2. 美团链接

### 美团链接怎么填

这里不是随便填一个网址，而是填“带有 `userId` 和 `token` 参数”的完整美团链接。

系统会自动从链接中提取：

1. `UserID`
2. `Token`

如果链接里缺少这些参数，系统会提示无法提取。

### 添加成功后

Token 会出现在列表里，并显示对应状态：

1. 在线
2. 检查中
3. 不在线

你也可以点击：

- `刷新所有状态`

来检查所有 Token 是否仍然有效。

## 5. 查询页主要区域说明

登录后，查询页主要分为三块：

1. `Token管理`
2. `查询任务`
3. `津贴查询`

简单理解：

- `Token管理`：保存和维护你的美团账号
- `查询任务`：查订单
- `津贴查询`：查当前账号当前地址下的津贴商家

## 6. 如何查询订单

### 第一步：选择 Token

在 `查询任务` 区域中，先从下拉框选择要查询的 Token。

如果没有 Token，请先回到上面先添加。

### 第二步：选择查询方式

现在支持两种常用方式：

1. 一键查询
2. 手动输入订单 ID 查询

#### 方式 A：一键查询

在页面中点击：

- `一键查询`

系统会按当前设置自动查询这个账号的订单。

#### 方式 B：手动输入订单 ID

在 `或手动输入订单ID` 输入框里，每行填一个订单 ID，然后点击：

- `查询手动输入的订单`

### 第三步：查看结果

查询结果通常会显示：

1. 订单 ID
2. 订单标题
3. 订单状态
4. 下单时间
5. 其他接口返回的订单信息

如果你已经加载了订单列表，也可以勾选后点击：

- `查询选中订单`

## 7. 如何查询津贴

津贴查询在页面下半部分，支持：

1. 大额津贴
2. 小额津贴（免单）

这两种可以分别查询，互不影响。

### 第一步：选择津贴类型

在 `津贴查询` 区域顶部，先点选：

1. `大额津贴`
2. `小额津贴（免单）`

### 第二步：确认当前 Token

津贴查询会使用当前选中的 Token。

页面会显示：

```text
当前津贴查询使用 Token：xxx
```

如果这里还是“请先选择Token”，说明你还没有在上面的订单区域里选择账号。

### 第三步：读取地址

系统在你选择 Token 后，会自动读取这个账号的历史地址。

默认会自动选中第一条地址，你也可以手动切换其他地址。

如果需要重新读取，可以点击：

- `刷新地址`

地址预览里一般会看到：

1. 地址名称
2. 地址详情
3. 地址 ID
4. 经纬度
5. 最近使用时间（如果有）

### 第四步：创建津贴任务

确认地址后，点击：

- `创建津贴任务`

系统会在后台自动分页查询，并持续刷新结果。

### 第五步：查看任务进度

任务运行时，页面会显示：

1. 当前状态
2. 当前页
3. 最近新增商家数
4. 累计商家数
5. 停止条件

### 第六步：查看津贴结果

查询完成后，可以看到：

1. 津贴摘要
2. 津贴商家列表
3. 每个商家的活动信息
4. 商品级津贴明细
5. 领券按钮
6. 打开美团 App 按钮

你还可以：

1. 搜索店铺名称
2. 切换地址看不同地址的津贴列表
3. 切换大额 / 小额看不同结果

## 8. 大额津贴和小额津贴有什么区别

页面里会分成两个标签：

1. 大额津贴
2. 小额津贴（免单）

它们的结果分开保存、分开展示。

也就是说：

- 查了大额，不会覆盖小额
- 查了小额，也不会覆盖大额

同一个地址下，你可以分别查看两种津贴结果。

## 9. 常见按钮说明

### Token 相关

- `添加Token`：新增一个美团账号
- `刷新所有状态`：检查所有 Token 是否在线
- `编辑`：修改 Token 备注名
- `删除`：删除这个 Token

### 订单相关

- `一键查询`：快速发起订单查询
- `加载订单列表`：读取订单列表
- `查询选中订单`：查询已勾选订单
- `查询手动输入的订单`：按手工填写的订单 ID 查询

### 津贴相关

- `刷新地址`：重新拉取历史地址
- `创建津贴任务`：开始查询当前地址津贴
- `清空`：清空当前页面展示状态
- `领券`：打开对应商家的领券链接
- `打开美团 App`：跳转对应商家

## 10. 常见问题

### 1）注册成功但无法登录

可能有两种原因：

1. 当前系统未开启自动审核，还在等待管理员审核
2. 用户名或密码输入错误

建议先看注册成功时的页面提示，再重新登录。

### 2）添加 Token 时提示无法提取 UserID 和 Token

说明你填写的美团链接格式不对。

请重新获取完整链接，再粘贴进去。

### 3）Token 显示不在线

说明这个 Token 当前可能已失效。

处理方式：

1. 重新获取新的美团链接
2. 删除旧 Token
3. 重新添加

### 4）津贴查询提示“请先选择地址”

说明当前账号的历史地址还没有加载成功，或者你没有真正选中地址。

处理方式：

1. 先确认已选择 Token
2. 点击 `刷新地址`
3. 重新选择一个地址
4. 再点击 `创建津贴任务`

### 5）津贴列表为空

可能原因：

1. 当前地址下暂时没有可用津贴
2. 这个 Token 已失效
3. 当前查询类型下没有命中的商家

建议：

1. 换一个地址再试
2. 切换大额 / 小额再试
3. 刷新 Token 状态再试

### 6）为什么不同地址的津贴不一样

因为津贴结果和地址强相关。

不同地址返回的商家范围、活动范围可能都不同，这是正常现象。

## 11. 推荐使用顺序

第一次使用，建议按下面顺序操作：

1. 打开登录页
2. 注册账号
3. 登录账号
4. 添加美团 Token
5. 刷新 Token 状态，确认在线
6. 先测试订单查询
7. 再选择地址创建津贴任务
8. 分别查看大额津贴和小额津贴结果

---
