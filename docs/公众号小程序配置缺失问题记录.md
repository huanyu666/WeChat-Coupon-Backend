# 公众号小程序配置缺失问题记录

## 问题现象

公众号 `gh_bdfb8233fa30`（雅俗共赏家）在接收到用户分享的美团小程序卡片时，**没有正常解析出商家券链接、小程序跳转按钮等内容**，仅显示了默认提示或降级文案（如“点击下方链接查看详情”但无实际链接）。

## 根因分析

历史根因是：当时小程序解析逻辑主要依赖 `miniprogram/miniprogram_config.toml` 中的分公众号配置。

- 每个公众号通过其**原始 ID**（如 `gh_xxxx`）作为 TOML 的 section 名来查找配置。
- 如果该公众号在 `miniprogram_config.toml` 中没有对应的配置段，程序在解析小程序消息时**读不到任何开关和文案**，只能返回默认提示或跳过处理。
- 本次问题即 `gh_bdfb8233fa30` 在该文件中**完全缺失**配置段。

当前版本已经改为运行时配置优先。新增或调整公众号业务配置时，不再要求手改 TOML 或重启服务；应先在后台 `/wechat-account-settings` 保存配置，保存后会写入 `runtime-data/wechat_accounts.runtime.json` 并热加载。

## 解决方案

### 2026-04-29 后续修复

该问题已经从“必须修改 TOML 文件并重启服务”改为“后台面板可直接配置”：

- `/wechat-account-settings` 现在可以维护美团小程序卡片回复、商家券查看回复、小程序链接文本回复、美团短链回复、商家券列表提示语和菜单 CLICK 事件回复。
- 新增公众号即使没有 `miniprogram/miniprogram_config.toml` section，也会获得通用默认美团小程序回复配置；保存后台配置后会写入运行时账号配置并立即热加载。
- `text_processors/click_event_responses.toml`、`text_processors/meituan_link.toml`、`text_processors/meituan_miniprogram_link_processor.toml`、`text_processors/merchant_coupon_prompts.toml` 的分公众号可变内容也可以通过后台覆盖。
- TOML 文件现在只作为默认模板和兼容旧配置使用，新增或调整公众号业务开关时不再需要直接改代码或改文件。

以下旧方案仅作为历史排查记录保留。

### 3. 历史方案：重启服务生效

历史版本中，由于 `config/config.py` 在**服务启动时**加载 TOML 配置，修改文件后**必须重启 Python 服务**才能生效。当前版本通过后台保存运行时配置时不需要重启。

```bash

WX_SERVICE_SOCKET_PATH=/run/wx_service-python/wx_service.sock ./.venv/bin/python run_server.py
```

## 当前通用处理模板

以后新增公众号遇到类似问题时，按以下步骤处理：

1. **确认公众号原始 ID**：在公众号后台“设置与开发 -> 公众号设置 -> 原始ID”中查看（格式为 `gh_xxxx`）。
2. **进入后台配置**：打开 `/wechat-account-settings`，选择或新增该公众号账号。
3. **补齐业务配置**：维护美团小程序卡片回复、商家券查看回复、小程序链接文本回复、美团短链回复、商家券列表提示语、菜单 CLICK 事件回复等账号级配置。
4. **保存并热加载**：点击保存后配置写入 `runtime-data/wechat_accounts.runtime.json`，服务会热加载，无需重启。
5. **仅在特殊情况下参考 TOML**：如果需要复制历史默认文案，可参考 `miniprogram/miniprogram_config.toml` 等模板文件，但不要把它作为日常配置主入口。

## 关键文件

- `runtime-data/wechat_accounts.runtime.json` —— 当前账号级业务配置主存储
- `/wechat-account-settings` —— 当前账号级业务配置入口
- `miniprogram/miniprogram_config.toml` —— 历史模板和兼容默认值
- `config/config.py` —— 负责合并 TOML 默认值和运行时配置
