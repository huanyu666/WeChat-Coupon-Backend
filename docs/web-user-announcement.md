# Web 端使用说明（精简版）

Web 端地址：

- `https://98vx.cn/web/login`

## 使用流程

1. 先注册账号并登录
2. 进入查询页后点击 `添加Token`
3. 粘贴美团链接，系统会自动提取 Token 和 UserID
4. 添加成功后可直接使用

## 可以做什么

### 订单查询

选择 Token 后，可直接：

- 一键查询订单
- 或手动输入订单 ID 查询

### 津贴查询

选择 Token 后，系统会自动读取历史地址。

你可以：

1. 选择 `大额津贴`
2. 或选择 `小额津贴（免单）`
3. 选好地址后点击 `创建津贴任务`

查询完成后可查看商家列表，并直接领券。

## 注意事项

1. Token 不在线时，请重新获取新的美团链接并重新添加
2. 不同地址查到的津贴结果可能不同，属于正常情况
3. 注册后如果不能立刻登录，说明当前账号还在等待审核
